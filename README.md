# Ramsey Graph Verification in Lean

This repository contains Lean code to verify witness graphs for Ramsey lower bounds.

Current examples:

- `R(3,13) >= 61` (`R(3,13) ≠ 60`) (Reported in [1], witness graph data from [2])
- `R(4,13) >= 139` (`R(4,13) ≠ 138`) (Reported in [1], witness graph data from [2])

## Lean File Structure

- `Ramsey/BitGraph.lean`: graph primitives and arbitrary-size bitsets implemented with `Nat` (no `UInt64`)
- `Ramsey/Bounds.lean`: clique / independent-set search and lower-bound checks
- `Ramsey/Examples/R313.lean`, `Ramsey/Examples/R313Data.lean`: `R(3,13) ≠ 60` example
- `Ramsey/Examples/R413.lean`, `Ramsey/Examples/R413Data.lean`: `R(4,13) ≠ 138` example
- `Ramsey/Lean4webCheck/R313Lean4web.lean`: one-file Lean4web version for `R(3,13) ≠ 60`
- `Ramsey/Lean4webCheck/R413Lean4web.lean`: one-file Lean4web version for `R(4,13) ≠ 138`
